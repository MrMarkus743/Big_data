## 1. Цель работы
Изучить принципы динамической Just-In-Time (JIT) компиляции кода Python с помощью фреймворка Numba, исследовать различия между нативным (`nopython=True`) и объектным (`forceobj=True`) режимами генерации машинного кода, реализовать параллельные многопоточные вычисления с обходом ограничений Global Interpreter Lock (GIL) и векторизовать скалярные функции в универсальные функции NumPy (`ufunc`).

---

## 2. Постановка задачи и математическая модель
В качестве расчетной задачи используется генерация фрактала — **множества Мандельброта** в комплексной плоскости.

* Итерационная формула:
  $$z_{n+1} = z_n^2 + c, \quad z_0 = 0, \quad c \in \mathbb{C}$$
* Условие расходимости: точка $c = x + iy$ не принадлежит множеству, если $|z_n| > 2$.
* Преобразование в 8-битный оттенок серого:
  $$\text{color} = 255 - \frac{255 \times t}{t_{\max}}$$
  где $t$ — номер итерации, на которой произошло превышение радиуса 2, а $t_{\max} = 200$.

---

## 3. Требования к реализации и сравнительному анализу
Необходимо реализовать и сравнить производительность 5 режимов расчета для координатной сетки $2000 \times 2000$ (диапазон $x \in [-1.5, 0.5]$, $y \in [-1.3, 1.3]$):
1. **Чистый Python (Pure Python):** базовая функция `compute_point` и двойной цикл `for`.
2. **Numba JIT (Native Mode):** компиляция функции с предварительным «прогревочным» вызовом (`warm-up`) для исключения времени компиляции LLVM из замера.
3. **Numba Object Mode (`forceobj=True`):** принудительное сохранение инструкций интерпретатора CPython (исследование падения скорости).
4. **Параллельный режим (`parallel=True, nogil=True`):** многопоточное распределение внешнего цикла по ядрам CPU с помощью функции `prange`.
5. **Векторизация NumPy (`@vectorize`):** компиляция в многопоточную ufunc (`target="parallel"`).

Результирующее фрактальное изображение и график ускорения сохраняются в папку `images/`.
