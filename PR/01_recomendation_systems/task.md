# Практическое занятие № 1: Рекомендательные системы

**Дисциплина:** Теория обработки больших данных (ТОБД)  
**Тема:** Построение рекомендательных алгоритмов на основе совместной фильтрации и матричной факторизации (SVD)

---

## 1. Цель работы
Изучить принципы построения рекомендательных систем, этапы обработки кандидатов и метрики сходства. Реализовать алгоритмы коллаборативной фильтрации на языке Python с использованием библиотеки Scikit-Learn.

---

## 2. Постановка задачи
Имеются данные о взаимодействиях пользователей с каталогом контента и выставленных оценках (`data.csv` / MovieLens-100k).  
Необходимо построить рекомендательную модель, функционирующую по принципу: *«Пользователи, смотревшие те же фильмы, что и вы, также высоко оценили...»*.

### Требования к реализации:
1. Загрузка и предобработка данных, формирование разреженной матрицы «пользователь — элемент».
2. **Базовый подход:** Расчет попарного косинусного сходства между фильмами (Item-Based Collaborative Filtering) и выборка Top-N похожих позиций.
3. **Продвинутый подход:** Понижение размерности матрицы взаимодействий с помощью сингулярного разложения (`TruncatedSVD`), восстановление матрицы и предсказание рейтингов для непросмотренных позиций конкретного пользователя.
