# Лабораторная работа № 4.1: Графы свойств. Neo4j. Знакомство с Cypher

**Дисциплина:** Теория обработки больших данных (ТОБД)  
**Тема:** Модель графов свойств (Property Graphs), основы СУБД Neo4j и декларативный язык запросов Cypher

---

## 1. Цель работы
Изучить принципы графовых моделей данных, архитектурные особенности NoSQL СУБД Neo4j, освоить базовые конструкции языка Cypher для создания, фильтрации, обхода и удаления узлов и связей.

---

## 2. Задания лабораторной работы

### Задание 1. Создание узлов и связей
1. Создать первый узел с меткой `Person` и свойствами:
   * `name: "Alice"`
   * `age: 30`
2. Создать второй узел с меткой `Person` и свойствами:
   * `name: "Bob"`
   * `age: 25`
3. Установить направленную связь `KNOWS` (знаком) от Alice к Bob.
4. Проверить создание узлов и связи запросом:
   ```cypher
   MATCH (p:Person) RETURN p
   ```

### Задание 2. Создание и фильтрация узла
1. Создать узел с меткой `Movie` и свойствами:
   * `title: "The Matrix"`
   * `year: 1999`
   * `genre: "Sci-Fi"`
2. Проверить создание узла:
   ```cypher
   MATCH (m:Movie) RETURN m
   ```
3. Выполнить поиск фильмов, выпущенных после 1990 года:
   ```cypher
   MATCH (m:Movie) WHERE m.year > 1990 RETURN m.title, m.year
   ```
4. Выполнить поиск фильмов по жанру:
   ```cypher
   MATCH (m:Movie) WHERE m.genre = "Sci-Fi" RETURN m.title
   ```

### Задание 3. Удаление данных
1. Удалить связь `KNOWS` между Alice и Bob.
2. Удалить узел `Alice`.
3. Удалить узел `Bob`.
4. Удалить узел `Movie` ("The Matrix").
5. Убедиться, что граф полностью очищен:
   ```cypher
   MATCH (n) RETURN n
   ```

### Задание 4. Самостоятельная работа
1. Создать собственный граф знаний (граф свойств учебной группы: студенты, изучаемые дисциплины, преподаватели) и отразить связи в Neo4j.
2. Реализовать запросы на поиск связей и путей между сущностями.
