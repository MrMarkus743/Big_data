# Лабораторная работа № 4.1: Графы свойств. Neo4j. Знакомство с Cypher

## Описание и цели работы
Работа посвящена изучению модели графов свойств (Property Graph Model), развертыванию графовой СУБД Neo4j и освоению языка запросов Cypher.

В рамках лабораторной работы:
* Созданы базовые узлы (`Person`, `Movie`) и направленные связи (`KNOWS`).
* Реализованы запросы фильтрации по числовым и строковым атрибутам (`WHERE`).
* Изучен механизм удаления сущностей с сохранением ссылочной целостности графа.
* Смоделирован практический граф знаний учебного процесса (студенты, группа, курсы, преподаватели) и выполнены многошаговые выборки связей.

## Архитектура графовой модели

### 1. Модель базового задания
```text
(:Person {name: "Alice", age: 30}) ──[:KNOWS]──► (:Person {name: "Bob", age: 25})

(:Movie {title: "The Matrix", year: 1999, genre: "Sci-Fi"})
```

### 2. Модель самостоятельной работы (Учебный процесс)
```text
                     (:Group {name: "DE-18-25"})
                               ▲
                          [:STUDIES_IN]
                               │
(:Student {name: "Mark"}) ──[:ENROLLED_IN]──► (:Course {title: "Big Data Processing"})

```

## Ход выполнения и ключевые запросы Cypher

### 1. Создание данных
```cypher
CREATE (alice:Person {name: "Alice", age: 30})
CREATE (bob:Person {name: "Bob", age: 25})
CREATE (alice)-[:KNOWS]->(bob);
```

### 2. Выборка и фильтрация
Поиск фильмов, выпущенных после 1990 года с жанром `Sci-Fi`:
```cypher
MATCH (m:Movie)
WHERE m.year > 1990 AND m.genre = "Sci-Fi"
RETURN m.title, m.year;
```

### 3. Запрос для обхода графа (поиск однокурсников)
Поиск студентов, которые слушают те же курсы, что и студент Mark:
```cypher
MATCH (s:Student {name: "Mark"})-[:ENROLLED_IN]->(c:Course)<-[:ENROLLED_IN]-(peer:Student)
RETURN peer.name AS Classmate, c.title AS SharedCourse;
```

## Ответы на вопросы для самоконтроля к защите

### 1. Как создать узел с меткой Person и свойствами name и age?
С помощью команды `CREATE` с указанием метки через двоеточие и свойств в фигурных скобках:
```cypher
CREATE (p:Person {name: "Alice", age: 30}) RETURN p;
```

### 2. Каким запросом можно установить связь FRIENDS_WITH между двумя существующими узлами?
Сначала существующие узлы находятся через `MATCH`, а затем связь фиксируется оператором `CREATE`:
```cypher
MATCH (a:Person {name: "Alice"}), (b:Person {name: "Bob"})
CREATE (a)-[:FRIENDS_WITH]->(b);
```

### 3. Как найти все узлы типа Movie, выпущенные после 2000 года?
Через оператор `MATCH` с условием `WHERE`:
```cypher
MATCH (m:Movie)
WHERE m.year > 2000
RETURN m;
```

### 4. Почему перед удалением узла нужно сначала удалить связанные с ним отношения?
В Neo4j строго соблюдается ссылочная целостность графа: в базе не может существовать «висячих» связей, которые ведут в несуществующую вершину. Если попытаться удалить узел оператором `DELETE a`, при наличии хотя бы одного входящего или исходящего ребра Neo4j заблокирует операцию и выдаст ошибку `ConstraintViolation`.  
*(Примечание: для одновременного удаления узла со всеми его связями в Cypher предусмотрена специальная конструкция `DETACH DELETE a`).*

### 5. Какой запрос покажет все связи определённого типа (например, ACTED_IN) в графе?
Запрос с анонимным шаблоном связи между любыми двумя узлами:
```cypher
MATCH (a)-[r:ACTED_IN]->(b)
RETURN a, r, b;
```
