5. Построить и оптимизировать генератор множества Мандельброта с расчетом на GPU.

## 2. Ключевые концепции CUDA в Numba

* **Конфигурация запуска ядра:**
  $$[blocks\_per\_grid, threads\_per\_block]$$
  где общее число запущенных потоков равно произведению этих параметров.
* **Индексация потоков:**
  * 1D массив: `position = cuda.grid(1)` или через встроенные регистры:
    $$position = blockIdx.x \times blockDim.x + threadIdx.x$$
  * 2D матрица: `x, y = cuda.grid(2)` с обязательной проверкой граничных условий (`if x >= shape[0] or y >= shape[1]: return`).
* **Разделение функций:**
  * Кернел (ядро): вызывается с хоста (CPU), исполняется на GPU, не возвращает значение через `return`.
  * Device-функция (`@cuda.jit(device=True)`): вызывается только из других функций на GPU, способна возвращать вычисленные значения.

## 3. Требования к реализации

1. **Диагностический модуль:**
   * Проверка доступности драйвера NVIDIA, версии CUDA, имени видеокарты и Compute Capability.
   * Наличие CPU-fallback режима на случай отсутствия физического GPU NVIDIA / CUDA toolkit на целевой машине.
2. **Эксперимент 1 (1D векторизация):**
   * Удвоение элементов массива ($my\_array \times 2$) с безопасной проверкой границ при $threads \times blocks > N$.
3. **Эксперимент 2 (2D матричные преобразования):**
   * Двумерная адресация элементов матрицы с предотвращением наложения расчетов между строками.
4. **Эксперимент 3 (Фрактал Мандельброта на GPU):**
   * Реализация device-функции `compute_point(c)` для расчета выхода точки за радиус 2.
   * Кернел `compute_all_points` с передачей скалярных вещественных границ вместо кортежей (обход ограничений типизации Numba CUDA).
   * Замер времени выполнения и сохранение результирующего изображения в `images/mandelbrot_gpu.png`.
