## 1. Цель работы
Изучить принципы организации параллельных и распределенных вычислений с использованием библиотеки Dask. Освоить ленивые вычисления (lazy evaluation), устранить антипаттерны преждевременной материализации данных и провести сравнительное профилирование производительности (время выполнения и потребление памяти).

## 3. Задачи для выполнения

### Задача 1.1. Расчет скользящей средней и построение динамического ряда
1. Загрузить исходные данные временных рядов урожайности.
2. Провести три базовые операции в парадигме Dask:
   * Фильтрация (отбор значимых диапазонов);
   * Агрегация (`groupby` / среднее по регионам);
   * Преобразование (расчет производных признаков).
3. Построить динамический ряд урожайности выбранного региона и рассчитать скользящую среднюю (Rolling Window) с окном сглаживания.
4. Выполнить визуализацию исходного и сглаженного временного ряда средствами Matplotlib.

### Задача 1.2. Профилирование и оптимизация кода
1. Смоделировать исходный неоптимальный код с антипаттерном: вызов `.compute()` внутри промежуточных вычислений.
2. Реализовать оптимизированный пайплайн с ленивым выполнением и однократным вызовом `.compute()` в финальной точке графа.
3. Провести замеры времени выполнения обоих подходов, рассчитать процент ускорения и снижения нагрузки на память.
