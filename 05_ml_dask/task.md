# Практическое занятие № 3: Модели ML в Dask

**Дисциплина:** Теория обработки больших данных (ТОБД)  
**Тема:** Распределённое машинное обучение, блочная обработка признаков и кредитный скоринг с помощью Dask ML

---

## 1. Цель работы
Изучить принципы организации распределённого машинного обучения на базе библиотеки Dask ML, освоить работу с локальным кластером (`dask.distributed.Client`), потоковую предобработку признаков без переполнения оперативной памяти (Out-of-Core) и обучить распределённую модель логистической регрессии для решения задачи бинарной классификации.

---

## 2. Исходные данные и постановка задачи
* **Входной файл:** `data/logisticheskaya_regressia_dannye.xlsx` — таблица с признаками клиентов кредитной организации.
* **Бизнес-задача:** Кредитный скоринг (Credit Scoring) — автоматизированное принятие решения по заявке:
  * `1` — «выдать кредит клиенту»;
  * `0` — «отказать в выдаче кредита».
* **Целевая переменная:** бинарный признак решения по кредиту.

---

## 3. Требования к реализации пайплайна

1. **Инициализация вычислительного кластера Dask:**
   * Настройка локального кластера через `dask.distributed.Client` с ограничением памяти на рабочий процесс (`memory_limit='2GB'`).
   * Мониторинг вычислительного графа через веб-интерфейс Dask Dashboard.
2. **Загрузка и предобработка данных:**
   * Чтение датасета и преобразование в распределённые структуры (`dask.dataframe` / `dask.array`).
   * Выделение матриц признаков ($X$) и целевого вектора ($y$).
   * Потоковое масштабирование числовых признаков с помощью `dask_ml.preprocessing.StandardScaler`.
3. **Разбиение на выборки:**
   * Разделение на обучающую и валидационную выборки через `dask_ml.model_selection.train_test_split` (соотношение 80/20, `random_state=42`) с сохранением блочной структуры данных.
4. **Обучение модели логистической регрессии:**
   * Использование распределённого классификатора `dask_ml.linear_model.LogisticRegression`.
   * Параметры: оптимизатор `solver='lbfgs'`, L2-регуляризация (`penalty='l2'`), `max_iter=1000`.
   * Фиксация времени обучения.
5. **Подбор гиперпараметров (GridSearchCV):**
   * Оптимизация силы регуляризации $C$ по сетке с оценкой качества кросс-валидацией (`cv=3`, метрика `accuracy`).
6. **Оценка качества и визуализация:**
   * Расчет метрики `Accuracy` на отложенной тестовой выборке с помощью ленивых операций `dask.array`.
   * Построение гистограмм точности и временных затрат на обучение, сохранение диаграммы в `images/model_evaluation.png`.
